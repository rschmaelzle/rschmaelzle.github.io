Eine Kapelle in Ihrem Raum

Virtuelle Sakrale Bauten · St. Konrad Grävenwiesbach

Tippen Sie auf „In meinem Raum ansehen“, erlauben Sie die Kamera und richten Sie das Handy auf einen Tisch oder den Boden. Dann gehen Sie einfach um die Kapelle herum.
Am Computer können Sie die Kapelle mit der Maus drehen.
Ganz in Ihrem Raum erscheint sie, wenn Sie diese Seite auf dem Smartphone öffnen.
